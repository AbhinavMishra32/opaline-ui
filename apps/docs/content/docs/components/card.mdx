```tsx
import { Card } from "@opaline/ui"
```

`Card` is drawn with a hairline ring and a soft shadow rather than a border, so it reads as raised on any ground.

`CardRow` is a settings row: a label on the left, a control on the right, hairlines between rows.

For a working area inset into a window, like an app's main pane, use `Sheet`, a squircle surface on the page background:

```tsx
<Sheet className="m-2 flex-1">…</Sheet>
```

## Parts

`Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`, `CardRow`, `Sheet`.
