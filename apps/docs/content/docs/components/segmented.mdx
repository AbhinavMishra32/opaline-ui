<ComponentPreview name="segmented-demo" />

```tsx
import { Segmented } from "@opaline/ui"
```

One sunken track and one raised thumb sliding between equal segments. Equal widths let the thumb be pure CSS: nothing is measured, so it lands correctly on the first paint.

Use Segmented to **set a value**. To switch what a panel shows, use [View Switch](/docs/components/view-switch).
