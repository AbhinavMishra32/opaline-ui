```tsx
import { ChoiceGroup, RatingPicker } from "@opaline/ui"
```

A radio group underneath. Arrow keys move between options and Enter or Space picks, so moving never commits a choice by accident. An option's `shortcut` picks it from anywhere on the page outside a text field, and its key cap flashes so a keyboard pick is as visible as a click.

```tsx
<ChoiceGroup
  aria-label="Grade"
  options={[
    { value: "wrong", label: "Wrong", tone: "danger", shortcut: "1" },
    { value: "right", label: "Right", tone: "success", shortcut: "2" },
  ]}
  onValueChange={grade}
/>
```

## RatingPicker

Again, Hard, Good and Easy on keys 1 to 4, each with the interval it would schedule. `suggested` marks the option the scheduler would pick without picking it.

```tsx
<RatingPicker
  intervals={{ again: "<1m", hard: "6m", good: "1d", easy: "4d" }}
  suggested="good"
  onValueChange={(rating) => review(card, rating)}
/>
```

`include={["again", "good"]}` gives a two-button review, `labels` renames the answers and `shortcuts={null}` turns the keys off.
