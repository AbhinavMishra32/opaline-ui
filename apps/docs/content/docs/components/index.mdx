---
title: Components
description: Compact primitives with Spar's visual and interaction grammar.
---

Each component is copied into the consuming application. The API stays close to shadcn/ui, while the proportions, tokens, and interaction details follow Spar.

| Component | Purpose |
| --- | --- |
| Button | Primary, secondary, outline, ghost, destructive, and icon actions |
| Badge | Compact status and metadata labels |
| Card | Structured raised surfaces with complete composition |
| Input / Textarea | Dense text entry with consistent focus and invalid states |
| Switch | Binary settings with Spar's compact geometry and easing |
| Tooltip | Short contextual labels and keyboard hints |
| Dialog | Focused modal work with restrained glass depth |
| Separator | Hairline structure for dense layouts |
