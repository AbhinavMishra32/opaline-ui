## Variants

Use `default` for the single most likely action on a screen, `outline` or `secondary` beside it, and `ghost` in toolbars. `destructive` is tinted rather than filled: deleting should be deliberate, not loud.

## Icons

Mark an icon with `data-icon="inline-start"` or `"inline-end"` and the button tightens its padding on that side, so the icon sits optically centred.

```tsx
<Button>
  New thread <ArrowRight data-icon="inline-end" />
</Button>
```

## As a link

`asChild` renders the child element with the button's styles:

```tsx
<Button asChild variant="outline">
  <a href="/docs">Docs</a>
</Button>
```
