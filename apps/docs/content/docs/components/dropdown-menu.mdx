```tsx
import { DropdownMenu } from "@opaline/ui"
```

Menus are glass (`op-menu`). Submenus open along a pointer corridor, so moving diagonally toward a submenu doesn't close it on the way.

## Parts

`DropdownMenu`, `DropdownMenuTrigger`, `DropdownMenuContent`, `DropdownMenuItem`, `DropdownMenuCheckItem`, `DropdownMenuLabel`, `DropdownMenuGroup`, `DropdownMenuSeparator`, `DropdownMenuShortcut`, `DropdownMenuSub`, `DropdownMenuSubTrigger`, `DropdownMenuSubContent`.
