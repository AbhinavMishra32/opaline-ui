## AgentThread

<TypeTable
  type={{
    messages: { type: "ThreadMessage[]", required: true, description: "The conversation. See [Messages](/docs/agent-thread/messages)." },
    onSend: { type: "(text: string, attachments: ComposerAttachment[]) => void", description: "Called when the person sends, with the ready attachments. `(text) => …` still works. Omit it to hide the composer." },
    onStop: { type: "() => void", description: "Stops a running turn. Shown while the last turn is streaming." },
    attachments: { type: "ComposerAttachment[]", description: "Images on the draft. Controlled: add them in `onAttach`, clear them after `onSend`." },
    onAttach: { type: "(files: File[]) => void", description: "Files picked, pasted or dropped, filtered to images. Shows the attach button." },
    onRemoveAttachment: { type: "(id: string) => void", description: "Removes a chip." },
    onAnswer: { type: "(partId, answers: QuestionAnswer[]) => void | Promise<void>", description: "Answers a pending `question` part. A promise shows the card as sending until it settles." },
    onCancelQuestion: { type: "(partId) => void", description: "Shows Skip on the question card." },
    questionPlacement: { type: "\"composer\" | \"inline\"", default: "\"composer\"", description: "Where a pending question is answered: in the composer's place, or as a card in the transcript." },
    scrollKey: { type: "string", description: "Remembers this transcript's scroll position across remounts." },
    composer: { type: "Omit<ComposerProps, \"onSubmit\" | \"onStop\" | \"busy\">", description: "Everything else the composer takes." },
    header: { type: "ReactNode", description: "Above the first message." },
    empty: { type: "ReactNode", description: "Centred when there are no messages." },
    footer: { type: "ReactNode", description: "After the last message." },
    className: { type: "string" },
  }}
/>

It also takes every option of `ThreadConfig` and `ThreadEvents`.

## Composer

See [Composition](/docs/agent-thread/composition#the-composer).

```ts
type ComposerAttachment = Attachment & {
  status?: "uploading" | "ready" | "error" // default "ready"
  progress?: number                        // 0–1
  error?: string
}
```

## Functions

| Export | Signature |
| --- | --- |
| `reduceThread` | `(messages, event: ThreadEvent) => ThreadMessage[]` |
| `reduceThreadBatch` | `(messages, events: ThreadEvent[]) => ThreadMessage[]` |
| `useAISDKThread` | `(messages: AISDKMessage[], status?) => ThreadMessage[]` |
| `fromAISDK` | `(messages, status?, timings?, { questions? }) => ThreadMessage[]` |
| `formatQuestionAnswers` | `(questions, answers) => string`, the answer text for the agent |
| `questionExchange` | `(input, output) => { question, answer, choices }[]`, reads an ask tool call |
| `answersFromText` | `(questions, output) => QuestionAnswer[]` |
| `groupParts` | `(parts) => PartRow[]`, the rows a turn draws |
| `isOutcome` | `(part) => boolean`, an answered question |
| `pendingQuestion` | `(messages) => QuestionPart \| undefined` |
| `parseReference` / `collectReferences` | `[[kind:target\|label]]` → `{ kind, target, label }` |
| `plainMath` | `(text) => string`, `\(O(n^2)\)` → `O(n²)` |
| `closeOff` | `(json) => string`, closes a truncated JSON prefix |
| `defineTools` | `(registry) => registry`, typed |
| `defineTool` | `<Input, Output>(definition) => definition`, typed |
| `inferTool` | `(name) => { icon, orb, verb }` |
| `resolveTool` | `(part, registry) => { title, subject, detail, icon, orb, … }` |
| `splitTurn` | `(message) => { work, reply }` |
| `formatDuration` | `(ms) => string`, e.g. `"2m 14s"`, `"1d 2h 0m"` |
| `tokenize` | `(code, language) => Token[]`, the built-in highlighter |
