An agent's turn is two different things: the **work** (thinking, searching, reading, running) and the **answer**. Most chat UIs draw them as one stream, so the answer is buried under forty tool calls.

Agent Thread keeps them apart. While the agent works, every step is one row in a rail: a mark you read before the words, a verb, a subject. When the answer starts, the work folds into a single line, *Worked for 14s*, and the reply gets the room. The steps are a click away when you want them.

The demo above is a scripted stream played through [`reduceThread`](/docs/agent-thread/streaming), the same reducer a real agent's events go through. Type in the composer to run it again with your own question.

## Usage

```tsx
import { AgentThread } from "@opaline/ui/thread"

export function Chat() {
  const { messages, send, stop } = useYourAgent()
  return <AgentThread messages={messages} onSend={send} onStop={stop} />
}
```

The thread is controlled: you pass messages in and it draws them. Where they come from is up to you.

- **Your own agent loop.** Emit events and fold them with [`reduceThread`](/docs/agent-thread/streaming).
- **The Vercel AI SDK.** Pass `useChat` messages through [`useAISDKThread`](/docs/agent-thread/ai-sdk).
- **Anything else.** Build [`ThreadMessage`](/docs/agent-thread/messages) objects yourself. They're plain data.

## What you get

- **The work fold.** It opens while the agent works and compacts to *Worked for 2m 14s* when the reply starts. Short turns get a playful length (*one sip of coffee*); you can make it [precise](/docs/agent-thread/configuration#duration).
- **Step rows.** Each tool call is one row with a running orb that swaps to an icon when it finishes, a subject (a path, a query, a command), timing, a diff stat and an expandable payload.
- **Tool inference.** Unregistered tools still look right. `read_file` gets a file mark and *Read*, `web_search` a search mark and *Searched the web*, `mcp__github__create_pr` is recognised through its prefix. [Register](/docs/agent-thread/tools) a tool to take over its title, subject, detail or whole body.
- **Reasoning.** Thinking streams with a shimmering heading taken from its latest bold line, then settles to *Thought for 4s*.
- **Markdown and code.** A built-in renderer with tables, lists, quotes and highlighted code blocks with copy. Bring react-markdown or Shiki if you prefer.
- **Footer actions.** Copy, rating and your own actions under each reply; edit and resend on user messages.
- **Sticky scroll.** Follows the stream until the reader scrolls up, then stays put and offers a jump back.
- **Reduced motion.** Every entrance and fold respects `prefers-reduced-motion`, or turn them off with `animate={false}`.
