Opaline UI is a set of React components for building the interface of an agentic app. At its centre is the **Agent Thread**, a conversation view for agents that work before they answer. Around it are the pieces every agent app needs: a composer, model and mode pickers, permission prompts, settings, menus, a command palette, all on Radix and drawn in one set of materials.

It's opinionated in the way good desktop software is. The palette is achromatic and colour is reserved for verdicts (passed, slow, failed). Controls are compact, a 32px button rather than a 40px one. Sheets are squircles, menus are glass, and focus reads as a surface lifting rather than a blue ring.

## Principles

- **Quiet by default.** Nothing animates, glows or takes colour without a reason. A running step gets an orb; a finished one gets an icon.
- **Read before you click.** The thread is designed for scanning. Every step is one row: a mark, a verb, a subject. Detail is one click away, never in the way.
- **Plain data in.** Components take props and the thread takes an array of messages. There is no store, no provider you must wrap the app in, and no backend.
- **Composable when you need it.** `<AgentThread>` is the batteries-included version; `Thread`, `ThreadViewport`, `ThreadMessages` and `Composer` are the parts it's made of.
