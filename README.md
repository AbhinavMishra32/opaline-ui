# Opaline UI

The shared interface system behind Spar: quiet desktop surfaces, compact controls, warm neutral color, Geist typography, precise focus states, and motion that stays out of the way.

Opaline is distributed like shadcn/ui. Applications install source they can own and adapt instead of inheriting a sealed runtime package.

## Start the docs

```bash
npm install
npm run dev
```

The Fumadocs site runs at [http://localhost:3011](http://localhost:3011).

## Install a component

Until the docs site is deployed, install directly from GitHub:

```bash
npx shadcn@latest add AbhinavMishra32/opaline-ui/button
```

The first release includes the Spar theme and core primitives: Button, Badge, Card, Input, Textarea, Separator, Switch, Tooltip, and Dialog.
